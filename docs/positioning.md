# 立ち位置（既存の作業分析AIとの違い）

> 2026-11-04 に Ollo Factory（https://ollo.jp/ollo-factory/improvement-suggestions）の公開ページを読んで整理。仕組みの記述は公開情報からの推測を含む。

## Ollo Factory の仕組み（公開情報から）
1. 動画をアップロード（スマホ・固定カメラ。作業を止めず撮り直し不要）
2. 映像解析で人・物・機械の動きを読み取り、問題のある区間を時間単位で出す（姿勢推定・物体追跡が土台と推測）
3. IE（作業分析）の知識を学習させたAIが、動作のムダ・5S・人間工学・レイアウト・安全の観点で問題点・改善案・期待効果を出す
4. 会社独自の基準・事例集を渡せる
5. 別製品：字幕付き動画マニュアル、ベテランと新人の比較分析、稼働分析、姿勢評価
- 比較対象は「ストップウォッチ分析」＝量産ライン向けカイゼン（ムダ取り）。顧客は大手の量産現場。

## 似ているところ
「動画を撮るだけ」「区間に分ける」「動画マニュアル」「ベテランと新人の比較」。表面は似ている。映像解析の精度で戦わない（5日で追いつけない上、参加者ガイドの「画像解析」に当たる）。

## 根本から違うところ
| | Ollo Factory | AI技能コーチ |
|---|---|---|
| 目的 | ムダを見つけて削る（カイゼン） | 分かれ目を見つけて残す（伝承） |
| 見るもの | 動き（何をしているか） | 判断（なぜそうしたか） |
| 主な材料 | 映像 | ベテランの声＋映像は場面を示す役 |
| 向く仕事 | 量産・繰り返し作業（標準時間が前提のIE） | 一品物・試作・多品種少量（毎回違うのでIEが効かない） |
| AIの立場 | AIが指摘し人が選ぶ | 熟練者が主役。AIは確度の高い補足だけ。出どころをラベルで分ける |
| 知識の扱い | 社内資料を渡せる | 判断を4種類に分け、ローカル知識と安全は熟練者優先。AIは確度の低い情報を出さない |
| 力・感触 | 姿勢の負担を数値化 | 測れないものは例え・結果の状態・両端の失敗で残す |
| 新人への届け方 | 字幕付きマニュアル（見る） | 分かれ目で動画が止まり、問う（考えてから見る） |
| 対象分野 | 製造業特化 | 分野プロファイルで製造・調理・介護へ |
| 蓄積 | 比較で差分を出す | 溜まるほど体感が数値化していく |

**一言：Olloは「ムダ」を見る。うちは「分かれ目」を残す。** 主戦場は「毎回違う一品物の仕事」（仕事を分ける軸3）。

## 差をつけるために強める点
1. 「なぜ」を残すことに全振り。映像の動き検出はやらない。判断モデル（7分解・4種類）を前面に。本人に理由を聞いて承認させる工程が差。
2. 分かれ目で止まる教育モード。「見る」ではなく「問われて考える」。
3. 確度の門番。根拠なしの情報を出さない仕組みをデモで見せる（「提案なし」と返る場面をあえて見せる）。
4. 一品物・試作に効く段取りの判断（D）。量産IEが扱わない「何からやるか・どこを逃がすか」。
5. 製造の外へ出られる基盤。調理の分野プロファイルを薄くでも入れる。
6. 作る側のガラケー世代UI。改善担当者（PC）向けではなく、ベテラン本人がスマホで撮って承認する。

## デモ・概要での言い方（案）
「作業分析AIは『ムダ』を見つけます。でも試作のような毎回違う仕事では、削るムダより、ベテランの頭の中にある『分かれ目』が失われることが問題です。このアプリは、その分かれ目を本人の言葉で残し、新人が分かれ目で立ち止まって考えられるようにします。」
