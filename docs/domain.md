# 車の試作現場のカンコツ作業（題材の候補と、本命の使い道）

> 一般論からの一覧。作者の現場感覚で直す。勤務先の映像・資料は使わないので、ここに挙げた作業は「本命の使い道（README・概要で語る）」であり、デモで動かす題材は家庭で撮れる作業で代用する。

## 板金・成形
- ハンマリング／絞り・伸ばし：どこを叩けばどう動くか、叩く強さと回数、裏当ての当て方
- 面修正（面出し）：面のうねりを手のひらと光で読む、どこを押して・どこを削るか、ハイライトの見方
- 曲げ・スプリングバック見込み：材質・板厚ごとに「戻り」をどれだけ見込むか
- ロール・フレア：縁の処理、割れさせない加減

## 溶接・接合
- 薄板のTIG／MIG溶接：電流・速度・トーチ角、歪みを出さない順番（飛び石打ち）、熱の逃がし方
- スポット溶接の打点決め：打点の位置と順番、電極の当たり具合
- 歪み取り：どこを炙って・どこを冷やすか

## 手加工・仕上げ
- ヤスリがけ：当て方・押す方向・力の抜き方、面を倒さない
- ケガキ・穴あけ位置出し：基準面の取り方、ポンチの一打
- バリ取り：どこまで取るか（取りすぎもNG）
- 研磨・磨き：番手の進め方、磨き目の管理
- はんだ付け（試作ハーネス・基板）：こて先の当て方、温め時間、流れ具合の見極め

## 塗装
- 下地処理（パテ・サフェーサー）：パテの盛り方・研ぎ方、巣穴の処理
- 本塗装：ガンの距離・速度・重ね幅、色合わせ（調色）、垂れ・ゆず肌の回避
- ぼかし（部分補修）：境目をどう消すか
- 乾燥・磨き：磨くタイミング、コンパウンドの進め方

## 樹脂・内装・試作専用
- FRP・樹脂積層：樹脂量と脱泡、繊維の向き
- 手張り（表皮・レザー）：シワを出さない引き加減、コーナーの処理
- 3Dプリント品・切削品の後加工：サポート除去、寸法合わせの削り
- 現物合わせ：図面通りでは付かない時の「どこを逃がすか」の判断

## 組付け・調整
- 建付け調整（ドア・ボンネット・バンパー）：隙間・段差をどこで吸収するか、シムの入れ方
- 締付け・順番：歪みを出さない締め順、本締め前の仮締め
- 配線・配管の取り回し：干渉しない通し方、余長の処理

## 計測・判定
- 寸法測定のあて方：ノギス・マイクロの当て加減、基準の取り方
- 目視・手触りによる良否判定：キズ・うねり・打痕の許容
- 音・振動での異常察知：加工音・締付け音の変化

## 段取り（どの工程にも共通する暗黙知）
- 治具・固定方法の決め方：一品物をどう固定するか
- 工程順の決め方：歪み・熱・後工程を見越した順番
- 設備・工具の選定：「これならこの機械」「手でやる方が早い」の判断
- 精度の落としどころ：どこを詰めて、どこを逃がすか
- 納期・工数の見積もり：「これなら何日」の勘

## アプリの観点
- 面修正・塗装・歪み取り・建付け調整は、手の技能（A）と判断（B）がどちらも濃い「ベテランしかできない」代表格。
- 段取りの項目は、どの作業にも乗る横断的な暗黙知で、背景の課題（毎回ゼロから準備）に最も近い。
- デモ題材（家庭で撮れるもの）の候補：はんだ付け、ヤスリがけ、小物の塗装（缶スプレー）、パテ盛り・研ぎ。

## 本命作業と、家で撮れる代替作業の対応
| 本命（試作現場） | 家でできる代替作業 | 本命との近さ | 撮りやすさ・材料 |
|---|---|---|---|
| 面修正・パテ研ぎ | 小物にパテを盛って研ぐ。ハイライトで面を読む | ◎ | パテ・ヤスリ・当て板 |
| 塗装（下地〜本塗装） | 缶スプレーで小物を塗る（サフ→塗り→磨き） | ◎ | 缶スプレー・サフ・マスキング。屋外・乾燥待ちあり |
| ぼかし（部分補修） | 自転車やプラ製品のキズを部分補修 | ○ | タッチペン・コンパウンド |
| ヤスリがけ・バリ取り | 金属片や3Dプリント品の面出し・バリ取り | ◎ | ヤスリ・ワーク |
| ケガキ・穴あけ位置出し | アルミ板にケガいてポンチ→ドリル | ○ | ケガキ針・ポンチ・ドリル |
| はんだ付け | 基板や配線のはんだ付け | ◎（給餌機の実績と直結） | こて・はんだ |
| 薄板溶接・歪み取り | 家では難しい。はんだ付けの熱の入れ方で代用 | △ | 溶接機が要る |
| 現物合わせ・3Dプリント後加工 | 3Dプリント品を削って相手部品に合わせる | ◎（「どこを逃がすか」そのもの） | 給餌機の筐体部品 |
| 建付け調整 | 家具の扉・引き出しの隙間調整 | ○ | 家にあるもの |
| 締付け順・歪み | 家具や自転車の組立で締め順を意識 | ○ | 家にあるもの |
| 寸法測定のあて方 | ノギス・マイクロでの測り方 | ◎ | ノギス |
| 段取り（治具・工程順・工具選定） | どの作業でも「作る前に段取りを決める」場面を入れる | ◎ | 道具を並べて語るだけで撮れる |

### 題材のおすすめ順
1. 3Dプリント品の後加工・現物合わせ（＋ヤスリがけ）：段取りの判断と手の技能が1本に入り、給餌機の部品が使える
2. 缶スプレー塗装：デモ映えし段取りも濃いが、屋外作業と乾燥待ちで撮影に時間がかかる
3. はんだ付け：いちばん手軽だが段取りの要素が薄い
