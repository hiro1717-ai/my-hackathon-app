# デモ動画の台本（3分以内）

- 素材：アプリに入れた動画「サポート印刷設定のコツ」（マニュアル「3Dプリンター上手な印刷マニュアル」、5分38秒）。
  - 文字起こし済み、AI下書きは約31円、判断カード7枚は承認済み。
- 方針：スライドではなく**実際の操作**を見せる（Discord「デモ＞プレゼン」）。待ち時間はカットする。
- 映さないもの：
  - Tailscale のアドレス、本物の管理者ID・パスワード
  - 勤務先のファイル
  - Dock の関係ないアプリ
- 下の「ナレーション」は読み上げる文そのまま（＝音声の文字起こし）。合計で約880字、1分あたり約300字の速さで約3分。

---

## 0:00–0:15 課題

**画面**：タイトル「WAKAREME AI」→ ログイン画面

**ナレーション**
「ものづくりの現場には、マニュアルに書けない“分かれ目”があります。どこを見て、どこで判断を変えるのか。WAKAREME AI は、熟練の判断を作業動画から取り出し、次の人に渡すためのアプリです。」

## 0:15–0:35 撮るだけ

**画面**：Bambu Studio を説明しながら撮った動画（数秒）

**ナレーション**
「登録者がやることは、作業をしながら考えていることを声に出して撮るだけです。今回は、3Dプリンターでサポートを設定する作業を撮影しました。」

## 0:35–1:05 新規作成と AI 下書き

**画面**
1. 「＋ マニュアル新規作成」
2. 動画を選ぶ（必要なら既存マニュアルのPDF、AIへの細かい指示）
3. 料金の確認画面 →「OK、作成開始」
4. （カット）文字起こしと下書きの完了

**ナレーション**
「新規作成のページで動画を入れます。既存のマニュアルや、AIへの細かい指示も一緒に渡せます。作成前に、AIの料金の目安を表示します。今回は約30円です。OKを押すと、文字起こしからClaudeによる判断カードの下書きまで、自動で進みます。」

## 1:05–1:40 判断カードと承認

**画面**
1. 判断カード7枚の一覧
2. 「しきい値角度を45度にする」を開く（その場面だけ動画が流れる）
3. 判断モデル（メインモデル6項目、マーカー設定の分かれ目）
4. 「モデルを承認」

**ナレーション**
「動画は、一つの判断ごとにカードに分かれます。カードを開くと、その場面だけが再生されます。何を見て、どう判断し、なぜそうするのか。守らないとどうなるのか。AIの下書きを登録者が確かめて直し、承認して初めて、手順書に載ります。」

## 1:40–2:00 分岐図

**画面**：カードの分岐図（成功と失敗の導線）。枠をタップして直す →「分岐図を承認」

**ナレーション**
「判断を誤るとどうなるのか。成功と失敗の道すじを分岐図で示します。枠をタップすれば、その場で直せます。」

## 2:00–2:35 学ぶ（閲覧モード）

**画面**
1. 参照（動画つき手順書）
2. ショート動画（スワイプで次の手順）
3. 教育モード（並べ替え → 安全ポイント → 分かれ目の○×）→ 🏅

**ナレーション**
「学ぶ側は、動画つきの手順書のほか、ショート動画のようにスワイプして要点を見られます。教育モードでは、手順の並べ替えや分かれ目のクイズで理解を確かめ、全部正解すると完了の記録が残ります。」

## 2:35–2:50 トライの比較（撮れた場合）

**画面**：初心者のトライ動画 → AI比較の結果（違いの指摘）

**ナレーション**
