# 応募時に提出した文章

## ① これまでAIで作って自信があるもの

今回紹介する制作実績には、Codexを使用しています。個人で給餌機を開発し、基板設計、筐体・部品の3Dモデリング、制御プログラムの実装まで取り組み、完成させました。設計や部品の修正を重ね、機械・回路・ソフトウェアを一つの製品へまとめた点が、最も自信のある成果です。AIとの協働によって、個人でも複数の技術領域にまたがる開発を進められると実感しました。今回は、この経験を生かし、Claude Codeを使った新たな開発に挑戦したいと考えています。

## ② 本ハッカソンで作りたいものと、その理由

さまざまな分野のプロが持つ暗黙知を言語化・視覚化し、次の熟練者を育てる「AI技能コーチ」を開発します。

私は自動車系企業の試作部署で働いています。設備の進歩によって手加工の機会が減る一方、今も必要な技能が引退間近の熟練者に集中し、若手が学ぶ機会も失われつつあることに課題を感じています。また、図面上で成立する設計でも、加工の難しさ、工数、品質のばらつき、技能者の確保が実現の壁になります。

このツールでは、作業映像と熟練者への聞き取りから「何に注目し、なぜその行動を選び、どう加減しているか」を整理します。Claudeが判断理由を掘り下げる質問を生成し、本人が確認した説明を映像の該当場面と結び付けて教材化します。若手は次の行動と理由を考える練習や、実作業の振り返りを通じて学べます。現場の制約や工夫を設計・作業方法の改善へ返す機能も目指します。

今回はClaude CodeとClaude APIを使い、家庭でも収録できる作業や利用許可のある実演動画を題材に、一つの作業について、分析、聞き取り、教材化、判断練習までを試作します。

将来は製造、料理、介護などへ展開し、残された記録や熟練者の知見を手掛かりに、失われつつある技術の継承と再建を支援したいと考えています。人手不足の中でも技能を受け継ぐ人を育て、日本の「いい品質、いいものづくり」を実現し続ける一助となるよう取り組みます。
