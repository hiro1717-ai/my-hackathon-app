# WAKAREME テストピース WK-01（ケーブルフック）

実機トライ用のサンプルです。**条件を守らないと失敗する「分かれ目」をわざと入れた**形にしてあります。
この部品を「スライサー設定 → 印刷 → 取り出し → サポート外し」まで、しゃべりながら撮影し、WAKAREME AI に入れて判断カードを作ります。

| ファイル | 中身 |
|---|---|
| `wk01_cable_hook.stl` | 3Dモデル（mm。底板が下＝そのままの向きで置く） |
| `wk01_drawing.pdf` / `.png` | 三面図（第三角法・尺度2:1・分かれ目①〜⑤つき） |
| `make_model.py` / `make_drawing.py` | モデルと図面を作るプログラム（寸法を変えるときに使う） |

- 大きさ：50 × 30 × 34 mm、体積 約14 cm³（PLA で約17 g）
- 印刷時間の目安：0.2mm 積層・サポートありで 40〜60分（機種による）
- ⚠ **実機での印刷はこれから（2026-11-08 時点で未実施）**。分かれ目と手順は設計上の予定で、試した結果に合わせて直す。

## 分かれ目（守らないと失敗する条件）

| # | どこ | 守ること | 守らないと |
|---|---|---|---|
| ① | 向き | 底板をベッドに置く（STLのまま） | 横・逆さにすると、意匠面（アーム上面・立ち上がり）にサポート跡が付く |
| ② | アームの下の張り出し | サポートを付ける（しきい角45°） | 35°区画はOK、60°区画は下面が荒れる、90°区画（右1/3）は垂れて崩れる |
| ③ | 窓の上（20mmのブリッジ） | 冷却ファン強め・ブリッジは速度控えめ・「ブリッジにサポートしない」 | 冷却不足で垂れる。サポートを「どこにでも」にすると窓の中にもサポートが入り、外しにくい |
| ④ | Ø5.2の穴×2 | 印刷後にM5ネジが通るか確かめる | 縦の穴は細く仕上がりやすく、ネジが入らない（穴補正か、ドリル5.2で整える） |
| ⑤ | サポート外し | ニッパーの平らな面を部品側に、根元から。意匠面側は当て板。400番で軽く | 途中で切ると残りが長く、強くヤスると面が波打って戻せない |

## 撮影の流れ（あらかたの手順）

**しゃべるときのコツ**：アプリは声を文字にして判断カードを作ります。手順ごとに、次のことを声に出すとカードが埋まります。
「**何を見て**」「**どうなったら大丈夫／ダメか（境界）**」「**どうする**」「**どのくらい**」「**なぜ**」「**守らないとどうなる**」

### A. スライサー（パソコンの画面を撮る）
1. STL を読み込む。**底板が下**のまま（①）。「意匠面はアームの上。ここにサポートを付けたくないから、この向き」
2. 材料は PLA、ノズル0.4、積層0.2。
3. サポートを有効に。種類は普通（ツリーでも可）、**しきい角 45°**、置き方は「どこにでも（Everywhere）」（アームの下はベッドではなく底板の上なので）（②）。
4. **「ブリッジにはサポートしない」をオン**（③）。それでも窓の中にサポートが出たら、サポートブロッカーで消す。
5. 冷却ファン 100%、ブリッジのファン 100%、ブリッジの速度は控えめ（③）。
6. サポートと部品のすき間（上面Z距離）は 0.2mm 前後に。近すぎると外れにくく、遠すぎると下面が荒れる（⑤）。
7. スライスしてプレビューで確かめる：**サポートがアームの下（60°と90°の区画）だけ**にあり、**窓の中と意匠面に無い**こと。「35°の所はサポートなしでいける」
8. プリンターへ送る。

### B. プリンター（フィラメントのセットと印刷）
1. ⚠ ノズルとベッドは熱くなる。触らない。
2. フィラメントをセット（ノズルを 200〜220℃ に温め、押し込んで先から出てくるまで）。「色が切り替わってきれいに出たら OK」
3. ベッドをきれいに（指の脂は剥がれの原因）。
4. 印刷開始。**最初の層**を見る：「線がつぶれて、すき間なく並んでいれば OK。丸く浮いていたら止めてやり直し」
5. 窓の上（ブリッジ）を印刷するところを見る：「垂れていないか」（③）

### C. 取り出し
1. ⚠ **ベッドが冷めてから**（触れるくらい。PLA は冷めると外れやすい）。
2. プレートを軽くしならせて外す。工具でこじる時は手を刃の先に置かない。

### D. サポート外し（⑤）
1. ⚠ **保護メガネ**（サポートのかけらが飛ぶ）。切る向きは体の外へ。
2. ニッパーの**平らな面を部品側**に向け、**根元**に沿わせて外す。
3. 意匠面（アーム上面・立ち上がり）に当たる側は**当て板**を挟む。
4. 残ったバリは **400番で軽く**。強くやると面が波打つ。
5. 穴に M5 ネジを入れてみる（④）。きつければドリル 5.2mm で軽く整える。

## 失敗例も撮ると強い（比べるために）
- サポートなしで印刷 → 90° 区画が垂れる・60° 区画が荒れる（②）
- 冷却ファンを弱めて印刷 → 窓の上が垂れる（③）
- 横向きに置いて印刷 → 意匠面にサポート跡（①）
