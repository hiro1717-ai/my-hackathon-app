# WAKAREME テストピース WK-01（ケーブルフック）

実機トライ用のサンプルです。**条件を守らないと失敗する「分かれ目」をわざと入れた**形にしてあります。
この部品を「スライサー設定 → 印刷 → 取り出し → サポート外し」まで、しゃべりながら撮影し、WAKAREME AI に入れて判断カードを作ります。

| ファイル | 中身 |
|---|---|
| `wk01_cable_hook.stl` | 3Dモデル（mm。底板が下＝そのままの向きで置く） |
| `wk01_drawing.pdf` / `.png` | 三面図（第三角法・尺度2:1・分かれ目①〜⑤つき） |
| `make_model.py` / `make_drawing.py` | モデルと図面を作るプログラム（寸法を変えるときに使う） |

- 大きさ：50 × 30 × 34 mm、体積 約14 cm³（PLA で約17 g）
- 印刷時間の目安：0.2mm 積層・サポートありで 40〜60分（機種による）
- ⚠ **実機での印刷はこれから（2026-11-08 時点で未実施）**。分かれ目と手順は設計上の予定で、試した結果に合わせて直す。

## 分かれ目（守らないと失敗する条件）

| # | どこ | 守ること | 守らないと |
|---|---|---|---|
| ① | 向き | 底板をベッドに置く（STLのまま） | 横・逆さにすると、意匠面（アーム上面・立ち上がり）にサポート跡が付く |
| ② | アームの下の張り出し | サポートを付ける（しきい角45°） | 35°区画はOK、60°区画は下面が荒れる、90°区画（右1/3）は垂れて崩れる |
| ③ | 窓の上（20mmのブリッジ） | 冷却ファン強め・ブリッジは速度控えめ・「ブリッジにサポートしない」 | 冷却不足で垂れる。サポートを「どこにでも」にすると窓の中にもサポートが入り、外しにくい |
| ④ | Ø5.2の穴×2 | 印刷後にM5ネジが通るか確かめる | 縦の穴は細く仕上がりやすく、ネジが入らない（穴補正か、ドリル5.2で整える） |
| ⑤ | サポート外し | ニッパーの平らな面を部品側に、根元から。意匠面側は当て板。400番で軽く | 途中で切ると残りが長く、強くヤスると面が波打って戻せない |

## 撮影の流れ（あらかたの手順）

**しゃべるときのコツ**：アプリは声を文字にして判断カードを作ります。手順ごとに、次のことを声に出すとカードが埋まります。
「**何を見て**」「**どうなったら大丈夫／ダメか（境界）**」「**どうする**」「**どのくらい**」「**なぜ**」「**守らないとどうなる**」

### A. スライサー：Bambu Studio（パソコンの画面を撮る）
> 機種は **Bambu Lab H2S**。設定名は Bambu Studio の版で少し違うことがある。見つからないときは、設定の画面の 🔍（検索）で名前を探す。
> ⚠ 撮る前に：「最近のプロジェクト」に勤務先のファイルが出ていないか、アカウント名・プリンターのシリアルが映らないかを確認。

1. **プリンターとプレート**：左上の「プリンター」で H2S（0.4 ノズル）、プレートの種類を選ぶ。
2. **読み込み**：「準備（Prepare）」で `wk01_cable_hook.stl` を読み込む。
3. **向き（①）**：底板が下のまま。**「自動で向きを決める（Auto orient）」は押さない**（意匠面が下や横を向くことがある）。「意匠面はアームの上。ここにサポートを付けたくないから、この向き」
4. **材料と積層**：フィラメントは PLA（使うものに合わせて Bambu PLA Basic など）、プロセスは「0.20mm Standard」。
5. **サポート（②）**：「プロセス → サポート」で
   - 「サポートを有効にする」をオン
   - 種類：普通（自動）。ツリー（自動）でも可
   - **しきい角（Threshold angle）：45°**（これより寝た面にだけ付く）
   - **「ビルドプレート上のみ（On build plate only）」はオフ**：アームの下はプレートではなく底板の上なので、オンにするとサポートが付かず崩れる
6. **ブリッジ（③）**：窓の上にサポートが出ていないか見る。出ていたら、左のツールの「サポートペイント」で窓の中を「ブロック」に塗る（または「ブリッジにはサポートしない」がある版ならオン）。
7. **冷却（③）**：フィラメントの設定の「冷却」で、オーバーハングとブリッジのファンを強め（100%）。ブリッジの速度は「速度」で控えめのまま（初期値でよい）。
8. **サポートのすき間（⑤）**：「サポート → 上面 Z 距離（Top Z distance）」を 0.2mm 前後に。近すぎると外れにくい、遠すぎるとアームの下面が荒れる。
9. **スライスして確かめる**：「プレートをスライス」→ プレビューで、**サポートがアームの下の 60° と 90° の区画だけ**にあり、**35° の区画・窓の中・意匠面（アームの上）に無い**こと。「35° はサポートなしでいける」。印刷時間と使う量も声に出す。
10. **送る**：「印刷」でH2Sへ送る。「タイムラプス」「最初の層の確認」は好みで。

### B. プリンター：H2S（フィラメントのセットと印刷）
1. ⚠ ノズル・ベッド・庫内は熱くなる。扉を開けて手を入れるときは、止めてから。動いているヘッドには触らない。
2. **フィラメント**：AMS ならスロットに差し込む（画面で材料と色を確かめる）。外付けのスプールなら、タッチパネルの「フィラメント → 読み込み」で、先から新しい色がきれいに出てくるまで。「色が切り替わって、細く途切れず出れば OK」
3. **プレート**：表面をきれいに（指の脂は剥がれの原因）。しっかり奥まで載っているか。
4. **PLA と庫内の熱**：PLA は庫内が熱くなりすぎると詰まりやすい。プリンターの案内（扉・上ぶたの開け方、PLA 用の設定）に従う。
5. **印刷開始 → 最初の層を見る**：「線がつぶれて、すき間なく並んでいれば OK。丸く浮いていたら止めてやり直し」
6. **窓の上（ブリッジ）を印刷するところを見る（③）**：「垂れていないか」
7. **アームの下（②）**：90° の区画はサポートの上に乗っているか。

### C. 取り出し
1. ⚠ **ベッドが冷めてから**（触れるくらい。PLA は冷めると外れやすい）。H2S の画面でベッドの温度が下がったのを確かめる。
2. プレートを外して、軽くしならせて部品を外す。工具でこじる時は手を刃の先に置かない。

### D. サポート外し（⑤）
1. ⚠ **保護メガネ**（サポートのかけらが飛ぶ）。切る向きは体の外へ。
2. ニッパーの**平らな面を部品側**に向け、**根元**に沿わせて外す。
3. 意匠面（アーム上面・立ち上がり）に当たる側は**当て板**を挟む。
4. 残ったバリは **400番で軽く**。強くやると面が波打つ。
5. 穴に M5 ネジを入れてみる（④）。きつければドリル 5.2mm で軽く整える。

## 失敗例も撮ると強い（比べるために）
- サポートなしで印刷 → 90° 区画が垂れる・60° 区画が荒れる（②）
- 冷却ファンを弱めて印刷 → 窓の上が垂れる（③）
- 横向きに置いて印刷 → 意匠面にサポート跡（①）
