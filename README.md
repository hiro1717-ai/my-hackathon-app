# AI技能コーチ（仮）

> Built with Claude: Japan 2026 提出作品（開発中）。テーマ「あなたにしかない深さを」。

## 試作の現場は、毎回ゼロスタート

量産ラインの作業分析AIは「ムダ」を見つけます。標準の手順があり、同じ作業を繰り返すからこそ、ムダが見える。

試作の現場は違います。**毎回ゼロスタートが基本**です。治具も、設備も、材料も、工法も、案件ごとに全部変わる。標準の手順がないので、ムダを削る前に「どうやるか」を毎回考えるところから始まります。万能の設備やアプリを買っても解決しません。

それでも、熟練者には**これまでこなしてきた知見から、早く・安くやり切る方法**があります。どこが分かれ目で、そこでどちらを選ぶか。それは熟練者の頭の中にだけあり、本人も言語化する手間をかけられないまま、引退とともに失われようとしています。

このアプリは、その悩みに対して、

**熟練者の作業から「分かれ目」を見つけ、本人の言葉で残し、次の試作を早く・安くする**

ためのものです。ムダを見つけるAIではなく、分かれ目を残すAIです。

## 何ができるか（予定）
1. ベテランは、作業を撮ってしゃべるだけ。
2. アプリが、しゃべりから「素人とベテランの分かれ目」を読み取り、判断カード（何を見て・どう判断し・どう加減し・どうなったら止めるか）の下書きにする。
3. ベテランは「合ってる／直す」を押すだけ。本人が認めたものだけが手順書になる。AIは根拠のある補足しか出さない。
4. 新人は、動画が分かれ目で止まり「次にどうする？なぜ？」と問われながら、教わる人がいなくても作業できる。
5. 成功の導線／失敗の導線を分岐図で見て、自分の失敗がどの分かれ目から来たかを逆引きできる。

今回の題材は「3Dプリントで試作部品を1点作る」（車の樹脂部品の試作で使う3DPを、家庭の3DPに置き換えたもの）。本体は、分野プロファイルを差し替えることで製造・調理・介護などに広げられる基盤です。
