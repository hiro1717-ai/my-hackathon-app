# AI技能コーチ（仮）

> Built with Claude: Japan 2026 提出作品（開発中）。テーマ「あなたにしかない深さを」。

## 試作の現場は、毎回ゼロスタート

量産ラインの作業分析AIは「ムダ」を見つけます。標準の手順があり、同じ作業を繰り返すからこそ、ムダが見える。

試作の現場は違います。自動車部品の試作に限らず、一品物を作る現場、中小企業のオーダーメイドの仕事、多品種少量生産の全般に共通して、**毎回ゼロスタートが基本**です。治具も、設備も、材料も、工法も、案件ごとに全部変わる。標準の手順がないので、ムダを削る前に「どうやるか」を毎回考えるところから始まります。万能の設備やアプリを買っても解決しません。

## それでも熟練者は、なぜ早くやれるのか

同じ案件を前にしても、熟練者は若手より圧倒的に早く、安く、確実に仕上げます。理由は長年の知見です。

昔の試作は手作業が多く、削る・曲げる・合わせる・直すを自分の手で何百回も繰り返す中で、「ここが分かれ目だ」「この状態になったら止める」「こうなったら戻せない」という気づきを体で積み上げてきました。設備や図面が変わっても通用するのは、その気づきが「手順」ではなく「判断」として身についているからです。

## いま起きている難しさ

設備の進歩やDXで、手作業そのものは昔ほど必要なくなりました。それ自体は進歩です。

しかしその結果、**若手がベテランと同じ気づきを得る機会が、今の時代にはほとんどありません。** 手を動かして失敗し、分かれ目を体で知る場面が減った。一方で、設備や図面では解決できない場面は今も残っていて、そこは引退間近の熟練者に集中しています。技術は衰退し、気づきと学びの機会は失われ、熟練者の頭の中にある判断は、本人も言語化する手間をかけられないまま消えようとしています。

## 技能伝承は、試みられている。でも届いていない

現場が何もしていないわけではありません。ベテランに作業指導をしてもらい、若手が横で見て、見よう見まねでやってみる。そういう技能伝承は、どの現場でも試みられています。

それでも、同じ品質にはなりません。見て真似ても、ベテランが「どこを見て、なぜそうして、どこで止めたか」は目に映らないからです。できたとしても、ベテランの何倍もの工数とコストがかかり、それでは試作として成り立たない。結果として「ベテランに頼む」か「若手が時間をかけて品質の低いものを作る」かの二択になっているのが、悲惨ですが現状です。

## このアプリがやること

**熟練者の作業から「分かれ目」を見つけ、本人の言葉で残し、若手が分かれ目で立ち止まって考えられるようにする。** ムダを見つけるAIではなく、分かれ目を残すAIです。

1. ベテランは、作業を撮ってしゃべるだけ。
2. アプリが、しゃべりから「素人とベテランの分かれ目」を読み取り、判断カード（何を見て・どう判断し・どう加減し・どうなったら止めるか）の下書きにする。
3. ベテランは「合ってる／直す」を押すだけ。本人が認めたものだけが手順書になる。AIは根拠のある補足しか出さない。
4. 若手は、動画が分かれ目で止まり「次にどうする？なぜ？」と問われながら、教わる人がいなくても作業できる。
5. 成功の導線／失敗の導線を分岐図で見て、自分の失敗がどの分かれ目から来たかを逆引きできる。

## 仕組みの芯：分かれ目を分解し、AIと熟練者の役割を分ける

このアプリは「AIが作業を分析して答えを出す」ものではありません。**どこまでをAIが答え、どこからを熟練者にしか語れないか**を最初に分けています。

**分かれ目とは何か。** カンコツと呼ばれるものは、技そのものより「ここが分かれ目だと気づけること」と「そこでどちらを選ぶか」です。素人は分かれ目が見えていない。だからアプリは、熟練者のしゃべりから分かれ目1個ごとに、①何を見ているか ②正常と異常の境界 ③選択肢 ④加減 ⑤止める条件・次へ移る条件 ⑥時間の配分 ⑦素人がやるとどうなるか、の7つに分解して判断カードにします。

**判断には4種類ある。** 分かれ目での判断は、性質によって「誰が答えられるか」が違います。

| 種類 | 例 | 誰が答えるか |
|---|---|---|
| **知識**で決まる | 材料の性質、規格、工具の種類 | 公開されている一般知識は**AI**が根拠つきで答える。その会社・現場にしかないローカルな決まりは**熟練者**を優先 |
| **数値**で決まる | ノズル温度、オーバーハング角、締付けトルク、時間 | 測れるものは数値で残し、**AI**が根拠つきで答える |
| **体感**で決まる | ヤスリの力加減、面のうねり、音の変化 | **熟練者**の言葉と映像でしか残らない。「身近な例え」「正しいときに見える結果」「強すぎ・弱すぎの失敗」の3点で挟んで残す |
| **状況**で決まる | 何からやるか、どこを逃がすか、誰に聞くか | **熟練者**の判断の筋道を残す |

**AIの役割は、確度の高いことだけ。** AIがやるのは、しゃべりを分解して下書きを作ること、足りない欄を質問すること、そして根拠を示せる補足だけを添えることです。根拠を示せない情報は出しません。安全に関わることと、現場固有のローカルな知識は、常に熟練者の判断が優先されます。判断カードには「熟練者の判断」か「AIの提案（熟練者が承認済み）」かの出どころが必ず付き、どこまでが人の暗黙知で、どこからがAIの補足かが見えます。

**測れるものは、蓄積で数値になる。** 体感でしか語れなかった「軽く」「少し傾ける」も、複数の熟練者のカードが溜まるほど「1〜2往復、1往復1秒」「15〜30°」のように数値の候補が浮かび、熟練者が認めれば数値として残ります。

## デモ：3Dプリンタで自動車部品の試作を模擬する

今回のデモでは、**自動車の樹脂部品の試作を家庭の3Dプリンタで模擬**します。試作部品を1点、「設計の段取り → 印刷の設定 → 後処理」まで通して作り、その中の分かれ目（印刷の向き、サポートの付け方、意匠面の守り方、後処理の力加減など）を熟練者役の作者が撮ってしゃべり、アプリが判断カードと動画手順書にします。

作者の勤務先の映像・図面・資料は一切使っていません。題材は家庭で撮れる作業のみです。

## 今後の応用

このアプリの本体は「分かれ目を見つけて残す」仕組みであり、3Dプリンタはその一例です。分野ごとの観点・失敗例・安全・質問テンプレを「分野プロファイル」として差し替えることで、製造（板金・溶接・塗装・組付け）、設計、飲食店の調理、介護など、**毎回状況が変わり、熟練者の判断が結果を左右する仕事全般**に広げていきます。
